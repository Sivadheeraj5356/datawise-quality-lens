# Datawise Quality Lens

A client-side data-quality inspector for Datawise-style data intelligence workflows. Paste a JSON array or CSV sample and the tool reports missing values, duplicate keys, malformed emails, outliers, a quality score and next actions. It runs entirely in the browser and stores no data.

## Run

Open `index.html` in a browser. No server, dependency, or API key is required.

## Test

```bash
node test.js
```
